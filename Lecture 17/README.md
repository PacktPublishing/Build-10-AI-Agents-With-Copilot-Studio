# Lecture 17: How to Build a Comparison Report Builder That Checks Sales Against Forecast, Flags Gaps and Creates a Word or Excel Report

**In this folder:** Comparison-Report-Builder-Build-Sheet.docx

**Resources:** Pashun Sports Comparison Report Template.docx, Report Summary.xlsx, Pashun Sports Orders.xlsx, Pro Tee Forecast.xlsx *(in the Resources folder)*

Use Comparison-Report-Builder-Build-Sheet.docx to copy the description, instructions and tool setup, then adapt the four gap definitions to a dated spreadsheet from your own work. To follow the demo exactly, connect the tools to Pashun Sports Orders.xlsx (which has a Month column, for example 03/2026) and Pro Tee Forecast.xlsx, add Returns Policy.docx as knowledge, and point the output tools at Pashun Sports Comparison Report Template.docx or the ReportSummary table in Report Summary.xlsx.

## To follow along exactly

In SharePoint, upload Pashun Sports Comparison Report Template.docx and Report Summary.xlsx to a document library named Reports, then in Excel for the web format the Report Summary data as a table named ReportSummary.

In Word desktop, use the Developer tab to replace each {placeholder} in Pashun Sports Comparison Report Template.docx with a plain text content control so Populate a Microsoft Word template can fill it.

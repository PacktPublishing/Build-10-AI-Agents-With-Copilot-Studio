# Lecture 13: How to Build a Meeting Actions Follow-Up Helper That Turns a Transcript Into Planner Tasks and Reminders Using Teams and Work IQ

**In this folder:** Meeting-Actions-Follow-Up-Helper-Instructions-and-Test-Messages.docx

**Resources:** Pro Tee Launch Check-In Transcript - 2026-03-03.docx *(in the Resources folder)*

Download the transcript from one of your own Teams meeting recaps and attach it in the test panel, or use Pro Tee Launch Check-In Transcript – 2026-03-03.docx as the sample transcript, with Project Pages.docx as the agent's project knowledge. Copy the description, instructions, flow settings, tool descriptions and test messages from Meeting-Actions-Follow-Up-Helper-Instructions-and-Test-Messages.docx, swapping in your own team roster, Planner plan and Teams channel. Work IQ is optional. If your agent cannot read the attached transcript, use the optional Read transcript topic on the card, or paste the transcript text into the chat.

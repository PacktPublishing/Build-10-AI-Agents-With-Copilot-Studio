# Lecture 23: Bonus Lecture: How to Coordinate Your Agents Behind One Business Assistant Hub Using Connected and Child Agents

Use Business-Assistant-Hub-Routing-Sheet.docx to copy the descriptions, hub instructions, child agent instructions and six test messages, then rewrite the specialist list and descriptions to match your own agents and log any misroutes as you retest.

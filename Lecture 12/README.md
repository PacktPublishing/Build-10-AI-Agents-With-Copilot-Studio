# Lecture 12: How to Build an Onboarding Helper That Creates Planner Checklists and Sends Welcome Emails From New-Starter Details

**In this folder:** Onboarding-Helper-Prompts-and-Instructions.docx

**Resources:** New Starter Onboarding.docx, Onboarding Task Templates.csv *(in the Resources folder)*

Publish New Starter Onboarding.docx as a page on your own SharePoint site, or swap in your team's real first-week steps, and add it as knowledge alongside Returns Policy.docx and Pro Tee Range Brief.docx. Load Onboarding Task Templates.csv into a SharePoint list, or replace its rows with your own onboarding tasks. Copy each name, instruction, prompt and message from Onboarding-Helper-Prompts-and-Instructions.docx into Copilot Studio as you build.

## To follow along exactly

In SharePoint, create the Onboarding Task Templates list from Onboarding Task Templates.csv (just the default Title column, six rows) and add the New Starter Onboarding page to the same site.

In Microsoft Teams, add an empty Planner plan called New Starter Onboarding to a team you own.

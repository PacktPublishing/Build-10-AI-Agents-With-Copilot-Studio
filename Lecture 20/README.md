# Lecture 20: How to Build a Stakeholder Report Helper That Writes a Narrative Update for Each Audience on a Schedule

**In this folder:** Stakeholder-Report-Helper-Build-Sheet.docx

**Resources:** Pashun Sports Orders.xlsx, Return Requests.csv *(in the Resources folder)*

Use Stakeholder-Report-Helper-Build-Sheet.docx to copy the description, instructions, test messages and workflow instructions, then swap in your own audiences, sources and recurring update.

## To follow along exactly

In SharePoint, create a list named Return Requests from Return Requests.csv using New > List > From CSV.

In Excel for the web, make sure Pashun Sports Orders.xlsx is saved in OneDrive or SharePoint and formatted as a table named Orders.

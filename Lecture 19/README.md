# Lecture 19: How to Build an Email Follow-Up Helper That Chases Suppliers in Outlook and Tracks Replies

**In this folder:** Supplier-Follow-Ups-List-Template.docx, Email-Follow-Up-Helper-Prompt-Sheet.docx

**Resources:** RE RAS-2304 Replacement stock for order PS-1042.eml, RE RAS-2310 Corrected invoice with bulk discount.eml *(in the Resources folder)*

Build your own list from Supplier-Follow-Ups-List-Template.docx using three items you are really waiting on, then paste the description, instructions, knowledge description and tool descriptions from Email-Follow-Up-Helper-Prompt-Sheet.docx, swapping in your own escalation and finance contacts. Add your own supplier or vendor agreement as knowledge, or use Ridgeline Apparel Supply Agreement.docx if you are following the Pashun Sports demo. Send yourself a test reply with a Reference in the subject, or send the text of RE RAS-2304 Replacement stock for order PS-1042.eml and RE RAS-2304 Replacement stock for order PS-1042.eml's companion RE RAS-2310 Corrected invoice with bulk discount.eml from a second test mailbox to try the reply-matching and finance-routing tests.

## To follow along exactly

In Outlook on your own computer, open each .eml file and forward or resend its subject and body from a second test mailbox to the address set as Contact Email in your list.
